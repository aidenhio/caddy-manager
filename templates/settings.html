Caddy API

Connect API

Lets Caddy Manager read live stats from Caddy's own admin API -- currently used to power the Dashboard's Current Requests widget. Enter the address Caddy's admin API listens on, e.g. caddy.example.com:2019 (defaults to http:// if no scheme is given). Leave blank to leave that widget unavailable.

Caddy Manager must be able to reach this address directly.

Caddy Logging

Log Output Directory

Overrides the directory written into a block's output file line when logging is enabled, the path Caddy itself will write that block's access log to. This is separate from the Logs directory path in Directories, which is where Caddy Manager looks to list, tail, and delete log files on its own side. Use this option to set different paths when Caddy and Caddy Manager don't share the same filesystem view of the logs volume. Leave this blank to keep using the Logs directory path for both.

Blank defaults to the Logs directory path ({{ cfg.log_dir or (cfg.root_dir + '/logs' if cfg.root_dir else 'root_dir/logs') }}). Existing blocks keep the path they were created with until next edited or re-created.
