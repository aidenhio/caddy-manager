General Settings

Preview Page Options

Controls what's shown on a site block's Preview page.

Displays the raw metadata sidecar file alongside the Caddy config on a block's Preview page.

Log Viewer

Controls how many lines the Logs page's "More" button shows from the end of a log file.

Must be a positive whole number of lines.
Read fresh from the file each time -- capped at 2000 lines regardless of this setting.

Certificate Expiry

Controls when the Certificates page's Status column flags a certificate as "Expiring soon" instead of "Valid".

Must be a positive whole number of days.
Caddy attempts renewal starting 30 days before expiry by default -- the default here (37) gives it a week of retries before flagging a cert, so "Expiring soon" tends to mean renewal needs attention rather than just "due soon."
